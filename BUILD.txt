Treatment Companion — build tag: unified-header
================================================

WHAT CHANGED
------------
One unified page header everywhere. The brand ("Treatment Companion" + sage
chevron) and the menus now share a single line on every page, and the account
menu is always hard right.

Two reported issues fixed:
  1. Account menu drifted LEFT on some pages. Cause: those headers used
     `justify-between` with the controls as the only child, which pins a lone
     child to the left. Now every header has a left (brand) and a right
     (controls) group, so the account menu can never drift left.
  2. Brand and menus were on SEPARATE lines (and the second strip looked empty
     when a page header was sparse). Cause: the brand was a separate global
     "BrandBar" strip rendered above each page's own header. That strip is now
     removed; the brand lives inside each page header.

-------
- NEW  components/layout/AppHeader.tsx  — shared header: brand left; optional
       back / title / patient-name (middle) / actions slots; help + account
       always right. Width matches the page content column (no JS alignment).
