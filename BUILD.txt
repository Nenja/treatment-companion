BUILD: training-row-wearable-module   (patient-page layout corrections)
=========================================================================
1) "Start treatment cycle" moved to the TOP of the left context column
   (above the patient banner), as a normal-size primary button instead of a
   full-width block buried at the bottom — leads the visit without shouting.

2) TRAINING is now in the icon row (medication / physio / history / export /
   training). It opens an inline panel with the training-days overview, which
   was previously an always-on section in the goals column.

3) WEARABLES left the icon row and became its own module in the left column,
   shown ONLY when:
     - a clinician has enabled wearables for the patient (new toggle on the
       patient-information page), OR
     - the patient already has wearable observations.
   The "or has data" rule means automated pairing will surface it later with no
   further change. The module links to the existing /clinician/observations.

MIGRATION 0077 (run in Supabase SQL editor; standalone copy attached)
   - patient.wearable_enabled (bool, default false)
   - set_patient_wearable_enabled(p_patient_id, p_enabled) RPC
     (clinician/therapist + active session; separate from set_patient_info).

DEPLOY
   Run 0077, then unzip / push to GitHub / Vercel builds. Page count 60.
