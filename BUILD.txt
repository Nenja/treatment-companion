WHAT THIS FIXES
---------------
In the patient check-in, the "Leave your check-in?" dialog's "Leave for now"
button did nothing when tapped.

Cause: it called a soft client-side navigation (router.push to the home path),
which is unreliable from the check-in page — the push was being swallowed, so
nothing happened. The app already had this problem on the post-submit "thanks"
screen and solved it there with a hard navigation (window.location). The Cancel
dialog was still using the old soft version.

Fix: "Leave for now" now uses the same reliable hard navigation home as the
thanks screen. The check-in draft is auto-saved on every change, so leaving this
way keeps your answers and you can resume the check-in later this week.
Only file changed: app/[locale]/checkin/page.tsx.

DEPLOY STEPS
------------
1. Unzip and push the contents to your GitHub repo (replace the working tree).
2. Vercel builds & deploys automatically on push.
3. No migrations to run, no new environment variables.

HOW TO CONFIRM IT'S DEPLOYED
----------------------------
1. Start a check-in, then tap Cancel (top-left) to open the dialog.
2. "Keep going" closes the dialog (unchanged).
3. "Leave for now" now returns you to the home screen.
4. Re-open the check-in: your previous answers are still there (draft kept).
