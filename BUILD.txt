Patient front-page fixes + an account-menu bug (WEB ONLY)

WHAT THIS IS
Six small, contained fixes to the patient front page and the account menu.
No database migration. No new dependencies. No text/translation changes.
Verified here: production build 62/62 pages, TypeScript clean.

HOW TO DEPLOY (your usual GitHub Desktop -> Vercel flow)
1. Unzip this file. It contains the 9 changed source files at their repo
   paths, plus updated HANDOVER.md, BUILD.txt, TRANSFER_PROMPT.md.
2. Copy the files into your local treatment-companion repo, keeping the
   folder structure (let them overwrite the existing files).
3. In GitHub Desktop: review, Commit, Push.
4. Vercel auto-builds and deploys.

DO NOT:
- run "npm install"  (there are no dependency changes)
- run any SQL in Supabase  (there is no migration)
- overwrite package.json or package-lock.json  (your repo's are newer)

WHAT CHANGED (plain language)
1. Care-team notes no longer crash when expanded. (A date that carried a
   timestamp was mishandled and threw the "Something went wrong" screen.)
2. Account menu: the highlighted text-size and Day/Night option now update
   instantly and stay correct. Before, the highlight stuck on the old choice
   and you couldn't re-pick the previous size until clicking something else.
3. The back arrow (top-left) is bigger and easier to tap.
4. Tapping the logo / app name (top-left) now takes you to your home screen.
5. The little arrows on the "Your goals" row, the "Show visit code" row, and
   the missed-check-ins list are now bigger, cleaner chevrons.
6. The divider between the visit-code row and the care-team notes section no
   longer shows a doubled line with a gap.
