BUILD: side-menu-option   (top vs side navigation, chosen at setup)
=========================================================================
WHAT THIS BUILD DOES
Adds a navigation-style choice for the clinician patient page:
  - Top menu  — icons in a row under the patient name (the current default)
  - Side menu — icons in a vertical rail down the left edge, content to the right
The choice is offered at setup (in the onboarding comfort step) with a small
illustration of each, and can be changed any time in the account menu. Both
options stay available.

CHANGES
- Migration 0078: profile.nav_style ('top' default | 'side').
- Preference plumbing on the profile (AppProfile.navStyle, useSetNavStyle,
  useNavStyle), mirroring the existing layout (wide/compact) preference.
- New NavStyleChooser component: two selectable cards, each with a wireframe
  preview. Shown in the onboarding wizard and the account menu (professionals,
  large screens — a side rail needs the width).
- PatientActionRow gained a vertical 'sidebar' variant. On the patient page,
  Side mode renders the action menu as a left rail and hides the top toolbar;
  Top mode keeps the toolbar. On phones/narrow windows both fall back to the
  stacked body row, unchanged.
- i18n (en + da) added; parity balanced.

DEPLOY
- Run migration 0078 in the Supabase SQL editor. Standalone copy attached.
- Unzip; push to GitHub; Vercel builds on push. Page count 60.
