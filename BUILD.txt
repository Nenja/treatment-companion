WHAT THE EXPORT DOES (web, normal GitHub -> Vercel)
On the clinician "Observations" page there is now a "Research data export"
section with a "Download REDCap CSV" button. It downloads one CSV containing
every research-consented patient's data across all their cycles - demographics,
treatment cycles, injections, goals, weekly check-ins, goal ratings,
physiotherapist assessments/ratings, and ITB - already coded to match your
REDCap data dictionary. Import it in REDCap with the Data Import Tool.

Each patient appears only under a study code (TC-0001, TC-0002, ...), never a
name. The clinic holds the code<->patient mapping.
