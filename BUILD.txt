WHAT IT DOES:
  Adds the code that, WHEN THE APP IS RUNNING AS THE NATIVE ANDROID/iOS APP, registers
  that phone's push token (after the user logs in) so reminders can reach it. In a normal
  web browser it does nothing at all - so deploying it to your website is completely safe
  and changes nothing visible today.

  It talks to the phone's push system through the bridge the native app provides at runtime,
  which is why the website needs no extra packages (and so this can't cause the "module not
  found" build failures we hit before).
