BUILD — localization-sv-nb-1
Swedish + Norwegian (Bokmal): first pass — the patient app core
INCLUDES ONE DATABASE MIGRATION (run it in Supabase)

WHAT THIS IS
The app now supports two more languages: Swedish (sv, at /sv) and
Norwegian Bokmal (nb, at /nb), alongside English (/) and Danish (/da).
This first pass translates the PATIENT app surface — the home screen, the
visit-code screen, the "suggest a goal" flow, and the weekly check-in
flow — into both languages. The Swedish and Norwegian are my first pass;
please have native speakers review the wording (same as we did for Danish).

Everything else (the onboarding tutorial, sign-in/sign-up, settings,
consent screens, and the whole clinician/physiotherapist/admin side) is
NOT translated yet — it automatically shows ENGLISH for now. Nothing
breaks; untranslated text simply falls back to English. I'll translate
those in the next passes.

HOW TO DEPLOY (two steps — SQL first, then files)
1) DATABASE (do this first):
   - Open Supabase -> SQL editor.
   - Paste and run the contents of:  0103_allow_sv_nb_locales.sql
     (It lets the database accept "sv" and "nb" as a saved language.)
2) WEB (GitHub Desktop -> Vercel):
   - Unzip. Copy these files into your repo (keep folder structure):
       i18n/routing.ts
       i18n/request.ts
       lib/supabase/auth.tsx
       messages/sv.json
       messages/nb.json
       supabase/migrations/0103_allow_sv_nb_locales.sql
     plus the updated HANDOVER.md / BUILD.txt / TRANSFER_PROMPT.md.
   - Commit and Push. Vercel rebuilds.

DO NOT: run "npm install", or overwrite package.json / package-lock.json.

HOW TO SEE IT
- Visit treatment-companion.vercel.app/sv   (Swedish)
- Visit treatment-companion.vercel.app/nb   (Norwegian Bokmal)
  The patient home, check-in, goals, and visit code should be in the new
  language; other screens will be in English for now.
- There is no in-app language switch yet — that picker is a later batch.
  For now the language follows the URL (/sv, /nb, /da, or / for English).

PLEASE REVIEW (native speakers)
- The Swedish and Norwegian wording on the patient home, the weekly
