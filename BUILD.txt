BUILD TAG: read-aloud
=====================================================================

WHAT CHANGED — read-aloud (text-to-speech) accessibility option
---------------------------------------------------------------------
Adds an opt-in "read aloud" feature for patients: a speaker button next
to key text that reads it using the device's own speech synthesis.

IMPORTANT CONTEXT: the other accessibility options discussed (text
size, colour/contrast palettes, night mode, layout, reduced motion)
ALREADY EXIST in the app's Appearance settings + account menu, so this
build only adds the genuinely missing piece. Voice input
(speech-to-text) was intentionally deferred.

Details:
- New per-user opt-in: profile.read_aloud (migration 0068), off by
  default. Written via the existing profile self-update path (same as
  text size / palette) - no new RPC.
- A toggle was added to the existing Appearance settings, next to night
  mode, so patients turn it on where the other appearance options live.
- When on (and the device supports it), a small speaker button appears
  on: the patient-home goal text, the weekly check-in goal/question
  (both NRS and GAS), and the safety notice. Tapping it reads the text.
- Read-aloud uses the browser's built-in speechSynthesis, on-device,
  in the app's current language (Danish or English). NO AUDIO LEAVES
  THE DEVICE - nothing is sent to any server.
- The button is automatically hidden for anyone who hasn't opted in or
  whose device/browser has no speech synthesis.


DEPLOY STEPS
---------------------------------------------------------------------
1. RUN THE MIGRATION:
       supabase/migrations/0068_read_aloud_pref.sql
   (adds profile.read_aloud; "add column if not exists", safe to re-run.
   If read_aloud is missing the toggle write will error.)
   Also run 0067 (from batch-a) if you have not already.
2. Deploy the code: push to GitHub -> Vercel as usual. No env changes.


HOW TO CONFIRM
---------------------------------------------------------------------
- As a patient, open Appearance settings (profile page) -> turn on
  "Read aloud". A speaker button should appear next to the goal on the
  home screen, on each check-in question, and on the safety notice.
- Tap it: the text should be read aloud in the app's language.
- Turn it off: the buttons disappear.
