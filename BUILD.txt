  app/[locale]/clinician/treatment/page.tsx - split into two components:
    - TreatmentRecordInner (thin shell): data fetching + the auth/role/no-
      session redirect effects + the loading/error guards. Renders the child
      only once data has loaded.
    - TreatmentRecordLoaded({ data, session, onSessionRefetch }): holds ALL the
      loaded-data hooks (form state, hydrate effect, the two previously-
      offending effects, derived values, handlers, the JSX).
    Because the child mounts only after the guards pass, every hook now runs

    "rendered more hooks than during the previous render" crash that the two
    useEffects-after-an-early-return caused.

    only when data is loaded, exactly as before). Props are typed from the
    hooks' own return types (NonNullable<ReturnType<...>['data']>), so nothing
    is loosened.

    react-hooks/rules-of-hooks is now a hard ERROR everywhere, including here.
