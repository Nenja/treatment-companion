Build tag: checkin-training-days

NEW: weekly training-day reporting in the check-in
- A new step is added to the check-in wizard, AFTER the goal ratings and
  BEFORE the comment/summary step: "Which days did you train this week?"
  Seven Mon–Sun toggles (multi-select). It's optional — selecting none and
  continuing means "no training this week".
- Stored on weekly_checkin.training_days as ISO weekday numbers
  (1=Mon … 7=Sun). NULL = not reported; {} = reported no training.
- The step is part of the normal flow (the wizard progress now shows it),
  and the selection is saved in the resumable draft like the ratings.

DATABASE — NEW MIGRATION (must run)
- supabase/migrations/0063_training_days.sql (also attached standalone):
    * adds weekly_checkin.training_days
    * adds set_checkin_training_days(checkin_id, days) — a small RPC the
      app calls right after submit to store the days (so the submit RPC is
      unchanged). It checks the check-in belongs to the calling patient.
- Run it in the Supabase SQL editor, then deploy this code.
