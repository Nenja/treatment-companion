BUILD: itb-goals   (ITB + BTX — slice 2: goals for both therapies)
=========================================================================
THE KEY IDEA
A weekly_goal_rating just links a check-in to a goal (no cycle constraint), and
the check-in submit rates exactly the goals the app sends it. So ITB goals do
NOT need a second active cycle (which would have hijacked every "resolve the
active cycle" RPC). Instead an ITB goal rides the patient's existing active
cycle and is simply TAGGED as ITB. The weekly check-in then carries it
automatically — the patient rates both therapies in one check-in — and the UI
groups goals by tag.

WHAT THIS BUILD DOES
- Migration 0080: approved_goal.therapy ('bont' default | 'itb') +
  set_goal_therapy RPC. No change to the check-in submit or any active-cycle
  resolver.
- Goal creation: RecordGoalForm / RecordGoalDrawer take an optional therapy;
  recording from the ITB section tags the new goal 'itb'.
- Clinician patient page: BoNT goals fill the main list; a new "ITB goals"
  section (shown when an ITB therapy is active or any ITB goal exists) lists
  ITB goals with the same progress chart + a "Record ITB goal" action.
- The patient's weekly check-in lists all active goals (both therapies) since
  they share the cycle — one check-in, both therapies.
- i18n (en + da) added; parity balanced.
