WHAT WAS WRONG WITH THE CHECK-IN TEST

  the app's: the loop looked for the rating buttons before the page had finished
  loading, so it skipped picking a rating, then waited forever on a Continue
  button that can't turn on until a rating is chosen. The app is fine.

WHAT THE TEST DOES NOW
  - Waits for the check-in screen to actually render before doing anything.
  - On each step, picks a rating and CONFIRMS it registered before moving on.
  - Only clicks Continue once it's actually enabled.
  - If the patient has no check-in due (e.g. a previous run already completed
    it — finishing a check-in uses up that week's prompt), the test SKIPS with
    a clear note instead of failing, so you can re-run the suite freely.
