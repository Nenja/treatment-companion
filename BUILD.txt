WHAT CHANGED & WHY:
  1) Security headers — the app now sends standard protective headers on every response
     (HTTPS-only/HSTS, anti-clickjacking, no MIME sniffing, referrer privacy, a permissions policy
     that keeps the camera/microphone available for video recording but blocks the rest, and it no
     longer advertises that it's built with Next.js). These are safe and on by default.
  2) Content-Security-Policy — included in "report-only" mode: the browser will REPORT anything
     unexpected (visible in developer tools) but will NOT block anything yet, so it cannot break the
     app. Your developer should click through all three roles + record a video with the browser
     console open, confirm there are no real violations, then switch it on for real (one-line change,
     noted in next.config.ts).
  3) Dependabot — a small config so GitHub checks monthly for outdated/vulnerable dependencies and
     opens a single grouped update PR. ALSO (one-time): in the repo Settings → Advanced Security,
     turn on "Dependabot alerts" and "Dependabot security updates" so urgent security fixes are
     flagged immediately.

HOW TO CONFIRM IT WORKED (after deploy): open the site, F12 → Network tab → click the first
  (document) request → Response Headers; you should see Strict-Transport-Security, X-Frame-Options,
  etc. Or paste the URL into securityheaders.com.
