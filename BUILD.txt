BUILD: edit-video-protocol
=========================================================================
WHAT THIS BUILD DOES
Lets the clinician edit the check-in video request + standardized task
protocol on an EXISTING goal. Until now these could only be set when the
goal was first created. NO DATABASE MIGRATION — frontend only; it reuses
the set_approved_goal_video_enabled (0062) and set_goal_video_protocol
(0071) RPCs.

CHANGES
- NEW components/clinician/VideoProtocolEditor.tsx — a modal that toggles
  the check-in video on/off and edits the recipe (instruction / framing /
  target length), via the existing useSetGoalVideoEnabled +
  useSetGoalVideoProtocol hooks.
- app/[locale]/clinician/patient/page.tsx — a new "Video task" button next
  to each goal's Retire button opens the editor, pre-filled.
- lib/supabase/clinicianPatient.ts — the clinician goal now carries its
  current video settings (videoEnabled + videoTask* added to the goal
  type/select/map) so the editor opens with the existing values.
- i18n: clinician.videoProtocol.* (en + da). Parity 1112 == 1112.

DEPLOY
1. Unzip; push to GitHub; Vercel builds on push. Page count unchanged (60).
2. No SQL to run.

HOW TO CONFIRM IT WORKED (needs a real browser + Supabase)
- On a goal with no video: open "Video task", enable it, fill the recipe,
  save; a subsequent check-in should offer the guided recorder with that
  recipe.
- On a goal that already has video: the editor should open pre-filled, and
  edits should persist.
- Disabling video should stop offering the recorder at check-in.

QA FLAGS
- Plain UI + existing RPCs; lower risk. Verify the modal layout on a real
  screen.
