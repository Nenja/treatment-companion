BUILD: record-goal-inline
=========================================================================
WHAT THIS BUILD DOES
Recording a goal no longer leaves the patient view. The "Record goal" button
now opens the goal form in a right-side slide-over over the chart; on save the
panel closes and the new goal appears in the list — no navigation, no reload.
NO database migration.

CHANGES
- New components/clinician/RecordGoalForm.tsx — the whole goal form (goal text,
  SMART line, NRS-vs-GAS choice with each one's config, optional weekly-video
  protocol, Cancel/Record), factored out of the /clinician/new-goal route so it
  can render in both places. Same create RPCs; on success it shows the existing
  toast. The create mutations already invalidate the patient query, so the goal
  list refreshes on its own.
- New components/clinician/RecordGoalDrawer.tsx — the slide-over: an overlay +
  right panel (max 560px, scrollable; full-height sheet on mobile) with focus
  trap + Escape, matching the existing ExportModal pattern.
- Clinician patient page: "Record goal" opens the drawer instead of navigating
  to /clinician/new-goal.
- /clinician/new-goal route kept as a thin wrapper around the same form, for
  deep links and the narrow fallback. No duplicated form code.
- No new translations (reuses newGoal.* + a11y.close). Parity 1122 == 1122.

DEPLOY
- No SQL. Unzip; push to GitHub; Vercel builds on push. Page count 60.
