BUILD: goal-history   (per-goal history view — build 2b of goal versioning)
=========================================================================
NO MIGRATION — reads existing tables. Ensure 0086 is applied.

WHAT THIS BUILD DOES
Each goal card on the clinician patient page gets a "History" button that opens
a per-goal timeline of its versions (oldest first), by lineage. Each version
shows:
- version number + cycle + a "Current" badge on the live one;
- the wording and calibration frozen at that version (NRS baseline->target; GAS
  the five anchors);
- the patient and therapist ratings recorded UNDER that version, as value chips
  (NRS 0-10; GAS as the -2..+2 level).

Versions are shown as separate segments rather than one continuous line,
because GAS anchors (and NRS targets) reset per version — values are only
comparable within the version they were rated against.

FILES
- lib/supabase/goalHistory.ts: useGoalHistory(lineageId) — all versions of a
  lineage + their ratings (patient from weekly_goal_rating, therapist from
  physio_goal_rating), grouped by version. Read-only.
- components/clinician/GoalHistoryModal.tsx: the timeline modal.
- clinician patient page: "History" button on bont + itb goal cards; modal.
