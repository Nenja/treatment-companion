BUILD: therapist-cycle-agnostic   (cycle-agnostic therapist suggestions)
=========================================================================
MIGRATION: 0085_cycle_agnostic_physio_suggestions.sql  — RUN THIS.

WHAT THIS BUILD DOES (final therapist-audit item)
A therapist seeing a patient before the first treatment cycle can now suggest a
goal / flag a muscle, instead of hitting "patient has no active treatment
cycle". Mirrors the patient-side fix (0081).

SCHEMA (0085)
- physio_goal_suggestion + physio_muscle_suggestion: treatment_cycle_id made
  nullable.
- Both submit RPCs recreated: resolve the active cycle if present, otherwise
  insert a null cycle (no raise). Session/consent gate unchanged.

NO BLACK HOLE
- The physician's read of physio suggestions now matches
  "treatment_cycle_id = current cycle OR is null" (was cycle-only), so a
  pre-cycle suggestion shows up in the Therapist-input panel once a cycle
  exists.

THERAPIST UI
- The no-cycle view of the therapist page now offers "Suggest a goal" (plus the
  status echo), so the action is reachable before a cycle. Muscle suggestions
  remain in the with-cycle action row.

DEPLOY

2. Unzip; push to GitHub; Vercel builds. Page count 60.
