Single change from the previous build (brand-follows-page-width); UI-only,
NO migration:
- The global brand strip now aligns PIXEL-PERFECT to each page's content
  column, whatever width that page uses. Instead of a fixed width, the
  strip measures the page's <main> element (its left offset + width) and
  matches its inner row to it; since <main> shares the same px-5 inset, the
  mark lands exactly at the content's left edge. It re-measures on window
  resize and on navigation, and falls back to a centred mid-width row
  before measurement / if no <main> is present.

Why this works everywhere: every page renders its content inside a centred
<main> (directly or via AppShell), so this adapts to the 480 / 720 / 1080
token widths AND the page-specific pixel widths (e.g. the 420px auth pages)
without hardcoding any of them.

How to confirm THIS build is deployed:
- BUILD.txt tag "brand-pixel-aligned".
- On any page, the chevron + "Treatment Companion" line up exactly with the
  left edge of that page's content, at any window width.
