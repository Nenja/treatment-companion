WHAT THIS BUILD DOES
Implements every concrete code/copy finding from the four audits in
docs/audits/ (all-roles-workflow, i18n-parity, clinician-cockpit-accessibility,
data-output-correctness). No schema change, no new behaviour for the DB.

DATA-OUTPUT CORRECTNESS (lib/ehrExport.ts)
- [High] Fixed the false "clear wearing-off": the return-to-baseline clause now
  requires the patient to have actually risen above baseline first
  (peak > initial). A stable/flat-good series (e.g. GAS +1 every week) no longer
  reports wearing-off.
- "Sustained N weeks" now breaks on a calendar gap (a skipped week), matching
  its own documented behaviour — it no longer counts across unreported weeks.
- Lower-is-better NRS goals get a "(NRS: lower is better.)" note so a low raw
  NRS isn't misread as a poor result.
- Added a reconciliation line when per-injection doses don't sum to the recorded
  total ("Note: listed injections sum to X units (recorded total Y).").
- default cases on sideLabel/guidanceLabel; buildGoalSentence now takes the goal
  (kind + nrs direction). Stale "single source" comment in lib/types.ts fixed.

I18N LEAKS KEYED (en + da, full parity)

- ExportModal fully keyed -> clinician.export.* (title/intro/copied/close/copy).
- GoalProgressView: chart aria-label, legend (Patient/Physiotherapist), and the
  week captions were hardcoded -> a11y.chart* and treatment.chart*.
- Danish fixes: visitChanges.checkinCount plural now translated; treatment.

ACCESSIBILITY (clinician cockpit)
- The cockpit now has an <h1> (the patient name wraps the existing info button).

CROSS-ROLE LEGIBILITY
