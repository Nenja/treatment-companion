BUILD: wide-layout
=========================================================================
WHAT THIS BUILD DOES
The approved wide-layout pass for the clinician patient page, plus a small
banner tweak. NO database migration — layout/markup only.

Gated on the existing "wide" layout preference (the default). Compact-layout
users and all mobile/narrow widths are unchanged.

CHANGES
- Two columns at the lg breakpoint: the page uses the full page-wide width and
  splits into CONTEXT (left) + GOALS (right). Left column = patient banner,
  since-last-visit summary, the look-up panels, and the new-cycle action.
  Right column = the goals (active + earlier). Goals now sit at the TOP of the
  right column instead of being pushed below the banner.
- Look-up tools (medication / therapist / history / export / wearable) move
  into a compact toolbar under the patient name in the header at lg; the body
  action row is hidden in that mode. The panels those tools open still render
  in the left context column. On narrow/compact, the body action row is used
  exactly as before.
- Banner: the "Week N since treatment" line was removed — the banner now shows
  only the treatment DATE (the modality pill stays top-right).
- Goals stack in a single column within the goals column (the page-level split
  now provides the horizontal space; the old 2-column goals grid was dropped).

DEPLOY
- No SQL. Unzip; push to GitHub; Vercel builds on push. Page count 60.
